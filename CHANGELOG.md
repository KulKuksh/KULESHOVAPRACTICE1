# Changelog

Все значимые изменения в проекте «PROSTOR» в рамках учебной практики (ПМ.04).

## [1.1.0] 

### Added
- **Новая функция**: сортировка товаров по убыванию цены через параметр `sort=price` (эндпоинт `GET /api/products`).  
  
- **Индексы для оптимизации запросов**:  
  - `idx_products_seller` на поле `seller_id`  
  - `idx_products_category` на поле `category_id`  
  (миграция Flyway: `V1_13__add_indexes.sql`)
- **Валидация входных данных**: в `ProductRequest` добавлены аннотации `@NotBlank`, `@NotNull`, `@Positive`, `@Size` с сообщениями; в контроллере использована `@Valid`.  

- **Глобальный обработчик ошибок валидации** – возвращает понятные сообщения (код 400).  

- **Мониторинг** – настроен Spring Boot Actuator (эндпоинты `health`, `info`, `metrics`).  
 
- **Документация**:  
  - Обновлён `README.md` (требования к системе, переменные окружения, troubleshooting)  
  - Создан `CHANGELOG.md`

### Fixed
- **Исправлен баг в `ProductController`**: отсутствовала проверка существования товара при удалении – теперь выбрасывается `EntityNotFoundException` (HTTP 404).  
  
- **Исправлен баг в `UserService` (валидация пароля)**: добавлены проверки на длину, наличие цифры и заглавной буквы.  

### Changed
- **Удалены неиспользуемые импорты**, улучшена читаемость кода.  

### Security
- Валидация DTO предотвращает сохранение некорректных данных.
- CSRF-защита (Spring Security) включена по умолчанию.

### Performance
- Добавлены индексы на `seller_id` и `category_id` – время запросов фильтрации сократилось на ~80% (при большом объёме данных).
- Настроен сбор метрик через Actuator для мониторинга памяти, CPU и HTTP-запросов.

### Documentation
- README.md дополнен разделами: «Требования к системе», «Переменные окружения», «Решение типовых проблем (Troubleshooting)».
- Создан CHANGELOG.md.
